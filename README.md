# 👋 Hi, I'm Girum Kenenisa

### Software Engineer • Full-Stack Developer • Backend & System Architecture

I’m a Software Engineer who enjoys building software from **the interface users interact with to the systems that power it behind the scenes**.

I work across the full stack, building responsive and well-structured frontends alongside reliable APIs, business logic, and data-driven backend systems. While I have a strong interest in backend architecture, I enjoy understanding the entire flow of an application — from designing the user experience to shaping the APIs, database, and system architecture underneath it.

I’ve built applications ranging from **business management systems and SaaS platforms to real-time applications and backend services**, working with technologies across the JavaScript/TypeScript, .NET, and Python ecosystems.

I’m particularly interested in **scalable application architecture, API design, authentication & authorization, multi-tenant systems, real-time communication, and event-driven architectures**.

> 💡 I like building software that is not only functional, but also **well-designed, maintainable, scalable, and enjoyable to use.**
